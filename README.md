# ☕ Trilha de Fundamentos: Java & POO

Este repositório é o meu laboratório central de estudos e práticas em Java puro. O objetivo principal aqui é **consolidar a base da Programação Orientada a Objetos (POO)** e Estruturas de Dados antes de avançar para a abstração de frameworks como o Spring Boot.

Este material serve como um catálogo pessoal de consultas para arquitetura de código, soluções de lógica e fundamentos de engenharia de software.

## > Objetivos do Repositório
* Construir uma fundação sólida em Java para atuar como Desenvolvedor Back-end.
* Registrar a evolução técnica através de exercícios práticos e mini-projetos.
* Aplicar a teoria na prática para criar códigos limpos, coesos e desacoplados.

## 📚 Roadmap de Estudos

Abaixo está a trilha de conceitos que estão sendo implementados e testados nos pacotes deste repositório:

- [X] **1. Fundamentos da POO**
    - Classes, Atributos e Métodos

    - Tipos primitivos vs Tipos referência
    - Vetores e manipulação de memória
- [X] **2. Modelagem e Relacionamentos**
    - Enumerações e Composição de Objetos
- [X] **3. Os Pilares da POO**
    - Herança (Extensão de comportamento)

    - Classes e Métodos Abstratos
- [X] **4. Tratamento de Erros**
    - Blocos `try/catch`
    - Criação de Exceções Personalizadas
- [ ] **5. Estruturas de Dados e Coleções**
    - Interfaces
    - Generics
    - Set, Map e Listas
- [ ] **6. Programação Funcional**
    - Programação Funcional
    - Expressões Lambda
- [ ] **7. Persistência e Banco de Dados (JDBC)**
